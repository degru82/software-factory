# 트리아지 라벨

스킬은 다섯 가지 표준 트리아지 역할로 말한다. 이 파일은 각 역할을 이 리포 이슈 트래커의 실제 라벨 문자열에 대응시킨다.

| mattpocock/skills 라벨 | 이 리포 라벨        | 의미                                   |
| ---------------------- | ------------------- | -------------------------------------- |
| `needs-triage`         | `needs-triage`      | 메인테이너가 검토해야 함               |
| `needs-info`           | `needs-info`        | 보고자의 추가 정보를 기다리는 중       |
| `ready-for-agent`      | `ready-for-agent`   | 명세가 끝나 AFK 에이전트가 바로 착수 가능 |
| `ready-for-human`      | `ready-for-human`   | 사람이 구현해야 함                     |
| `wontfix`              | `wontfix`           | 처리하지 않음                          |

스킬이 역할을 언급하면(예: "AFK 준비 완료 트리아지 라벨을 붙여라") 이 표에서 대응하는 라벨 문자열을 쓴다.

라벨 문자열 자체는 스킬과 맞추기 위해 영어 그대로 둔다. 실제로 쓰는 어휘가 달라지면 "이 리포 라벨" 열을 고친다.
